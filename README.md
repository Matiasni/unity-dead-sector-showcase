# Dead Sector

A top-down mission shooter made in Unity, inspired by the first Helldivers. It is a **portfolio sample**: a playable slice built to show gameplay architecture, not a finished game.

## About this project

- **It is a sample, not a final product.** The scope is a single mission, most of the art is placeholder (Unity primitives) and the balance is unpolished.
- **It is built on scripts created for a private personal project.** The core systems (movement, health, weapons, pooling, events, screens) come from that earlier work and are reused, adapted and extended here to put together a complete game from start to finish.
- **Some assets are AI-generated.** In particular, the visual side of the interface (the sprite atlas used by the menus and the HUD) was generated with AI.

## What you can play

**Mission "Operation Antenna"**

1. Pick your loadout: 2 of 3 weapons and 2 of 3 abilities.
2. Deploy on the map and complete the objectives:
   - **A — Hive:** destroy the nests.
   - **B — Radio tower:** start the uplink and defend it against the waves.
   - **C — Depot (optional):** recover the cache.
3. With A and B complete, the **extraction** unlocks: call it, hold the area and board the ship.

**Included systems**

- **Weapons:** assault rifle, shotgun and sniper, with magazine, reload and reserve ammo.
- **Abilities:** dash with invulnerability, sticky grenade, orbital drone, force shield and healing stim.
- **Enemies:** a melee one, a ranged one, a sniper that paints you with a laser before firing, one that charges in a straight line, and nests that spawn more enemies.
- **Reinforcements:** a limited number of respawns per mission.
- **Progression:** experience, levelling up and choosing upgrades.
- **Economy:** scrap dropped by crates and enemies, and terminals to buy ammo, stims and gear.
- **Languages:** English and Spanish, switchable from the menu.
- **Sandbox mode:** a test scene with dummies, zones and pickups.

## Technology

- **Unity** 6000.3.8f1 with the **Universal Render Pipeline**.
- **Input System** for the controls.
- **AI Navigation** (NavMesh) for the enemies.
- **TextMeshPro** for the whole interface.
- **WebGL** build to play in the browser.

## Architecture

What this project is meant to show is in the code:

- **Data in ScriptableObjects.** Weapons, abilities, enemies, attacks, waves, rewards and upgrades are defined as assets, and several of them work as factories for the behaviour they describe.
- **Generic pooling.** Projectiles, enemies, effects and drops all go through a single `PoolManager`.
- **Generic state machine** (`StateMachine<TState>`), used by the enemies and by the mission director.
- **Event bus** (`GameEvents`) that decouples gameplay from the interface.
- **Small interfaces** (`IDamageable`, `IHealable`, `IDamageModifier`, `IInteractable`, among others) instead of dependencies on concrete classes.
- **Localization** loaded from JSON, with texts updating when the language changes.
- **Visual effects** made with Unity's particle system and custom shaders, using textures generated by code.

## Structure

```
Assets/
├─ Scripts/      Game code, organised by system
├─ Data/         ScriptableObjects (weapons, abilities, enemies, mission, progression)
├─ Prefabs/      Player, enemies, weapons, mission, HUD
├─ Scenes/       MainMenu, Hub, Mission_OperationAntenna, Sandbox
├─ UI/           Interface atlas, fonts and styles
├─ VFX/          Effect shaders, textures, materials and prefabs
├─ Resources/    Language files
└─ Settings/     URP configuration and post-processing profiles
```

## How to open it

1. Clone the repository.
2. Open it with **Unity 6000.3.8f1** (or a nearby 6000.3 version) from Unity Hub.
3. Open the scene `Assets/Scenes/MainMenu.unity` and press Play.
